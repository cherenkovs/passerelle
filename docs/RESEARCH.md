> Дослідження ринку та методик, на якому побудовано «Passerelle».

### Головний висновок

**Ніхто не вчить французької з української.** Українець змушений вчити через англійську — це подвійний переклад, втрата нюансів і зайве когнітивне навантаження. Це не дрібниця: для дорослого учня опора на рідну мову (L1) прискорює засвоєння граматики в рази.

### Друга діра

Кожен продукт закриває **одну** методику: Duolingo — дриль, Anki — SRS, LingQ — інпут, Pimsleur — аудіо. Учень мусить платити за 3–4 підписки й склеювати їх вручну. Ніхто не поєднав це в одну систему.

## 2. Що насправді працює (доказова методика)

Ці принципи — не думки, а те, що стабільно підтверджується дослідженнями засвоєння мов. Кожен з них перетворено на конкретну механіку в застосунку.

1. **Spaced repetition (інтервальні повторення)** — крива забування Еббінгауза. → Алгоритм SM‑2 на кожному слові й граматичному правилі.
2. **Active recall > recognition** — згадати важче й корисніше, ніж упізнати. → Пріоритет вводу з клавіатури над вибором варіанта; MCQ лише як «м'яка» перша зустріч.
3. **Comprehensible input (i+1, Krashen)** — читати/слухати трохи вище свого рівня. → Градуйовані історії з тапом-на-слово, де 90–95 % слів уже знайомі.
4. **Retrieval + immediate feedback** — помилка без пояснення нічого не вчить. → Кожна перевірка дає ✅/❌ **і розбір українською**, чому саме так.
5. **Desirable difficulty** — легке навчання = слабка пам'ять. → Перемішування типів вправ, диктанти, продукування речень.
6. **Output & pronunciation loop** — треба говорити вголос. → TTS-модель вимовляє, розпізнавання мовлення слухає учня, порівнює.
7. **Частотність** — 1000 найчастіших слів = ~80 % розмовної французької. → Словник упорядкований за частотністю, а не за темами «зоопарк».
8. **Chunking / готові фрази** — мозок зберігає блоки, не окремі слова. → Вчимо `j'aimerais…`, `est-ce que…` як цілі одиниці.
9. **Contrastive analysis UA↔FR** — найшвидший спосіб пояснити дорослому. → Пояснення завжди відштовхується від української: «у французькій рід іменника часто НЕ збігається з українським: `une table` — жіночий, а «стіл» у нас чоловічий».
10. **Interleaving** — мішати теми, не блоками. → Сесія повторення тягне картки з усіх модулів.

## 3. Специфічні болі українця у французькій

Це список, який жоден англомовний курс не покриває. Він зашитий у пояснення й у «типові помилки»:

- **Артиклі.** В українській їх нема взагалі. Це болюча точка №1 → окремий модуль + постійні клоуз-вправи.
- **Рід іменника не збігається.** `le livre` (ч.) — «книга» (ж.); `la table` (ж.) — «стіл» (ч.). → Рід завжди вчиться разом з артиклем, ніколи окремо.
- **Носові голосні** `[ɑ̃] [ɛ̃] [ɔ̃]` — в українській відсутні. → Окремі фонетичні дриль-вправи з мінімальними парами.
- **`R` увулярне** проти українського розкотистого. → Пояснення артикуляції + аудіо-порівняння.
- **Німі закінчення.** `parlent` = `parle` на слух. → Диктанти саме на це.
- **Обов'язковий підмет.** Укр. «Йду додому» → фр. **`Je** vais à la maison`.
- **Порядок слів і заперечення `ne…pas`** — розрив дієслова.
- **Немає відмінків** → їхню роль грають прийменники `à / de / en`.
- **Дієслово «бути» не опускається**: «Він лікар» → `Il **est** médecin`.
- **Liaison** — зв'язування, якого в українській нема: `les_amis` [lezami].

## 4. Позиціонування «Passerelle»

> **Одна система замість чотирьох підписок, українською, безкоштовно, офлайн.**

Диференціація:

1. 🇺🇦 **Українська як мова-опора** — інтерфейс, переклади, пояснення, розбір помилок.
2. 🧠 **Усі чотири методики в одному циклі**: структурований курс → інпут (читання/відео) → SRS → продукування (говоріння/письмо).
3. 💸 **$0 вартості експлуатації** — озвучка через вбудований у браузер синтез мовлення, розпізнавання через Web Speech API, дані локально. Жодного платного API за замовчуванням.
4. 🔌 **Офлайн-first PWA** — усе працює в літаку.
5. 📓 **Зошит як перший клас** — власні нотатки, збережені слова, автоматична колода «мої помилки».
6. 🔍 **Прозорий прогрес** — видно, які саме навички просіли, а не абстрактні «очки».
