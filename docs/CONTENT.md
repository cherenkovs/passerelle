# Як додавати навчальний матеріал

Увесь контент — типізовані об'єкти в `src/content/`. Жодної зміни в компонентах не потрібно:
TypeScript підкаже, якщо щось пропущено, а рушій вправ підхопить нове автоматично.

---

## 1. Додати слово

`src/content/vocab.ts` — знайди потрібну групу й додай запис.

```ts
{
  id: 'la_cle',                     // унікальний, латиницею
  fr: 'la clé',                     // ЗАВЖДИ з артиклем для іменників
  uk: 'ключ',
  ipa: 'la kle',
  pos: 'n',
  gender: 'f',
  example: { fr: 'Où est la clé ?', uk: 'Де ключ?' },
  note: '⚠️ Жіночий рід, а український «ключ» — чоловічий.',
}
```

**Правила, які тримають якість курсу:**

- Іменник **ніколи** не пишеться без артикля — це головна ідея методики.
- `note` заповнюй тоді, коли є пастка саме для українця: розбіжність роду, німа літера,
  хибний друг, виняток. Порожнє поле краще за загальну фразу.
- `ipa` — реальна вимова, не транслітерація.

Нове слово одразу з'являється у Словнику, у тап-перекладі по всьому застосунку й може
потрапити в автогенеровані вправи.

### Частотне ядро

Крім тематичного словника є `src/content/core/` — ~1000 найуживаніших слів, розбитих на
смуги (`band-1.ts` … `band-6.ts`). Формат компактніший, бо записів багато:

```ts
// [id, français, українською, IPA, частина мови, (примітка)]
['w_cle', 'la clé', 'ключ', 'la kle', 'nf', '⚠️ Жіночий рід, а наш «ключ» — чоловічий.'],
```

Рід складено в частину мови: `nm` (чоловічий), `nf` (жіночий), `nmf` (спільного роду —
`l'élève`), `n` (тільки множина — `les gens`). Ранг присвоюється **автоматично** за позицією
в списку, тож нічого нумерувати вручну не треба.

Два списки зводяться самі: якщо слово вже є в тематичному словнику, воно лишається одне —
зберігає багатший запис і просто отримує частотний номер. Тому дублювати слово в ядрі
безпечно, а `npm test` окремо перевіряє, що жодне слово не потрапило до Словника двічі.

## 2. Додати урок

`src/content/courses/` — знайди модуль і додай об'єкт у `lessons`.

```ts
{
  id: 'm5l4',                       // moduleId + порядковий номер
  title: 'Назва українською',
  subtitle: 'Короткий підзаголовок',
  minutes: 12,
  newWords: ['la_cle', 'la_porte'], // id зі словника → підуть у повторення
  steps: [ /* теорія */ ],
  exercises: [ /* практика */ ],
}
```

### Кроки уроку (`steps`)

| `kind`          | Для чого                                                      |
| --------------- | ------------------------------------------------------------- |
| `intro`         | Вступ, мотивація, «навіщо це»                                 |
| `vocab`         | Список нових слів (`words: string[]` — id зі словника)        |
| `grammar`       | Правило: `body`, необов'язкові `table`, `examples`, `warning` |
| `dialogue`      | Діалог: `setting` + `lines[]` з `speaker / fr / uk`           |
| `pronunciation` | Фонетика: `pairs[]` з `fr / ipa / uk`                         |

У `body` працює проста розмітка: списки через `•` або `1.`, цитата через `>`, абзаци —
порожнім рядком, плюс два види виділення:

| Розмітка     | Для чого                                             |
| ------------ | ---------------------------------------------------- |
| `**жирний**` | Ключовий термін або форма, на яку дивимось           |
| `*курсив*`   | Французький приклад усередині українського пояснення |

Вкладати можна: `*Je **ne** comprends **pas**.*` — курсив показує, що фраза французька, а
жирний виділяє в ній потрібну форму. Те саме працює в `warning`, у клітинках `table`, у
`examples[].fr` та в `explain` / `hint` вправ.

Незакритий маркер не «з'їдає» рядок — він просто лишиться зірочкою на екрані. Саме тому
`courses.test.ts` перевіряє, що кожна зірочка входить у пару: помилка такого типу нічого не
ламає й інакше доїхала б до учня непоміченою.

Поле `warning` — це жовта плашка. Тримай її для **типової помилки українця**, не для
загальних зауважень.

**Кожен крок `grammar` автоматично потрапляє в довідник** (`/reference`) — окремо нічого
додавати не треба. Тому дай кроку назву, за якою його можна знайти: «Модель: форма ils
мінус -ent» гарна в уроці, але термін «subjonctif» має бути хоча б у `body`, у таблиці або
в `grammarFocus` модуля — інакше правило існує, а знайти його неможливо.

## 3. Типи вправ

Усі мають `id`, необов'язкові `prompt` (інструкція), `explain` (розбір після відповіді) і
`words` (id слів — помилка автоматично поверне їх у повторення).

```ts
// Вибір варіанта
{ kind: 'mcq', question: 'bonjour', speak: 'bonjour',
  options: ['добрий день', 'добрий вечір'], answer: 0, optionsAreFrench: false }

// Ввід із клавіатури
{ kind: 'type', question: 'дякую', answer: ['merci'], accents: true, hint: '…' }

// Пропуск ( ___ у реченні )
{ kind: 'cloze', sentence: 'Je ___ ukrainien.', answer: ['suis'],
  translation: 'Я українець.', options: ['suis', 'es', 'est'] }   // options → чипси замість вводу

// Пари
{ kind: 'match', pairs: [{ fr: 'merci', uk: 'дякую' }] }

// Аудіювання
{ kind: 'listen', audioText: 'Bonjour !', options: ['…'], answer: 0 }

// Диктант (діакритика перевіряється строго)
{ kind: 'dictation', text: 'Je suis étudiant.', translation: 'Я студент.' }

// Збірка речення з чипсів
{ kind: 'wordbank', question: 'Мене звати Марк.',
  answer: 'Je m’appelle Marc.', distractors: ['suis'] }

// Вимова вголос
{ kind: 'speak', text: 'Bonjour !', translation: 'Добрий день!' }

// Переклад UA → FR (найцінніший тип)
{ kind: 'translate', question: 'Я не розумію.', answer: ['je ne comprends pas'] }
```

**`answer` — це масив усіх прийнятних форм.** Додавай варіанти з апострофом і без,
з діакритикою і без неї, синонімічні побудови. Перевірка й так прощає одну друкарську
помилку та відсутні надрядкові знаки (окрім диктанту й іспиту), але явні варіанти надійніші.

## 4. Додати текст, аудіоурок або сценарій

- **Текст для читання** — `src/content/stories.ts` (нові — у `stories-2.ts`). Пиши власний
  або бери твір, що є суспільним надбанням (автор помер понад 70 років тому). Абзаци —
  пари `{ fr, uk }`, плюс `glossary` і `questions`. Переноси рядків зберігаються, тож вірші
  можна давати як вірші.

  **У `source` пиши правду.** Якщо текст скорочено чи переказано — так і напиши
  («Скорочено й адаптовано для рівня B1»). Приблизний «оригінал», відтворений по пам'яті,
  гірший за чесний переказ: учень має знати, чи бачить він Мопассана, чи нас.

  Пам'ятай, що абзац **озвучується**. Нотацію (`→`, IPA у дужках) `speakable()` вирізає, але
  не покладайся на це у полях, які існують лише для голосу.

- **Аудіоурок** — `src/content/videos.ts` (нові — у `videos-2.ts`). Без `youtubeId` текст
  озвучує синтезатор (працює офлайн). З `youtubeId` вбудовується відео, а `t` у транскрипті —
  секунда для перемотки.

  Синтезатор говорить **чітко**, тому не обіцяй у `blurb` того, чого урок не дає: він учить
  зв'язку звук → зміст і скорочених форм, а не швидкого мовлення носія. Розмовні редукції
  пиши так, як їх вимовляють («j'sais pas», «y a», «faut qu'on»), а повну форму давай у
  вправі — саме розрив між цими двома записами і є те, чого учень не чує.

  Клади в кожен урок **диктант**: це єдина вправа, яка перевіряє, що учень почув слова, а не
  вгадав зміст із контексту.

- **Розмовний сценарій** — `src/content/tutor.ts`. Кожна репліка — що каже вчитель і що
  очікується від учня, з масивом `accept` (усі прийнятні відповіді) та `hint`.
  Якщо відповідь відкрита — учень називає своє ім'я, своє місто, — додай
  `acceptPrefixes: ["je m'appelle", 'je suis']`: тоді зараховується будь-яке продовження
  формули. Інакше правильною була б лише та відповідь, яку вигадав автор курсу.

### Узгодження з учнем

Французька змушує обрати рід. «Je suis allé» і «Je suis allée» — це те саме речення про
двох різних людей, тож рід не можна вгадувати: сценарій проходять і Марина, і Сергій.

Познач вибір прямо в тексті — застосунок підставить потрібну форму:

| Розмітка                    | Чоловічий | Жіночий     |
| --------------------------- | --------- | ----------- |
| `Je suis allé{e}.`          | allé      | allée       |
| `Je suis ukrainien{ne}.`    | ukrainien | ukrainienne |
| `Je suis {vieux\|vieille}.` | vieux     | vieille     |

Коротка форма дописується до чоловічої (регулярні -e / -ne / -se), довга виписує обидві,
коли змінюється основа. Маркери розкриваються централізовано — у `TapText` і в озвучці, —
тож будь-який французький рядок може їх містити.

Два правила:

- **Не став маркер у поле, яке перевіряється** (`answer`, `options`, `sentence`): відповідь
  порівнюється буквально, а фігурну дужку ніхто не набирає. `npm test` це ловить.
- **Не прив'язуй чужий рід до учня.** «avec un ami» — це про друга, а не про учня;
  `un{e} ami{e}` зробило б стать друга залежною від статі учня.

В `accept` маркери ставити можна й варто: тренажер приймає обидві форми, бо це вправа на
розмову, а не на закінчення прикметників.

Учень може додати своє відео з YouTube прямо в застосунку — без коду.

### Завдання на письмо

`src/content/writing.ts`. Крім брифу й зразка, головне — `checks`: список того, що можна
перевірити **без здогадок**. Кожен `check` — набір фраз, будь-яка з яких зараховується;
`forbid: true` перевертає правило (знайшли — це проблема).

Фрази звіряються **по межах слів**, без урахування регістру й діакритики. Це не дрібниця:
доти, доки збіг шукався підрядком, «salutations distinguées» спрацьовувало як фамільярне
«salut» — тобто перевірка карала саме ту відповідь, яку мала б хвалити. З тієї ж причини
не полюй за закінченнями (`ais`): «je vais» їх теж містить. Перелічуй справжні форми.

`npm test` перевіряє, що **зразок проходить власні checks**. Зразок, який не виконує
свого ж завдання, навчає неправильного двічі.

## 5. Додати цілий модуль або курс

1. Створи модуль у `src/content/courses/` за зразком наявних.
2. Додай його в масив `modules` потрібного курсу в `src/content/index.ts`.
3. **Додай три проби в `src/content/placement.ts`** — інакше тест на визначення рівня не
   зможе перевірити цей модуль (`npm test` це впіймає).
4. Для нового курсу — додай об'єкт у `COURSES` і зміни `status` на `'ready'`.

Мапа курсу, замки, прогрес, тести й іспит підхопляться самі.

### Проби для тесту на визначення рівня

Проба перевіряє **структуру модуля, а не його лексику**: можна вільно володіти минулим
часом і не знати слова «баклажан». Три питання, тільки `mcq` або `cloze` з `options` —
нічого друкувати не треба.

Правильний варіант пиши **першим**: так набагато легше перечитувати й перевіряти, а перед
показом усі варіанти однаково перемішуються (`shuffleOptions`).

## Чекліст перед тим, як вважати урок готовим

- [ ] Кожен новий іменник — з артиклем.
- [ ] Є хоча б одна вправа на **продукування** (`translate`, `wordbank` або `dictation`),
      а не лише на впізнавання.
- [ ] `explain` пояснює **чому**, а не просто повторює правильну відповідь.
- [ ] Названо пастку для українця, якщо вона тут є.
- [ ] `newWords` заповнено — інакше слова не потраплять в інтервальні повторення.
- [ ] `npm run typecheck` і `npm test` проходять (тести ловлять дублікати, забутий рід і брак IPA).
